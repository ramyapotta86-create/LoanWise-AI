## 2. Required Input Features (Exact Names, Order & Types)

`Loan_ID` is **excluded**. Pass the exact **11 raw features** below in a single-row `pandas.DataFrame` (or use `build_input_dataframe()` in `ml/src/predict.py`):

| # | Exact Feature Name | Expected Input Type | Verified Dataset Values |
| :-: | :--- | :--- | :--- |
| 1 | `Gender` | `str` (or `None`) | `"Male"`, `"Female"` |
| 2 | `Married` | `str` (or `None`) | `"Yes"`, `"No"` |
| 3 | `Dependents` | `str` (or `None`) | `"0"`, `"1"`, `"2"`, `"3+"` (`"3+"` mapped to `3` inside pipeline) |
| 4 | `Education` | `str` | `"Graduate"`, `"Not Graduate"` |
| 5 | `Self_Employed` | `str` (or `None`) | `"Yes"`, `"No"` |
| 6 | `ApplicantIncome` | `float` / `int` | Non-negative number (`>= 0`) |
| 7 | `CoapplicantIncome` | `float` / `int` | Non-negative number (`>= 0`) |
| 8 | `LoanAmount` | `float` (or `None`) | Positive number (`> 0`) |
| 9 | `Loan_Amount_Term` | `float` (or `None`) | Positive number (commonly `360.0`) |
| 10 | `Credit_History` | `int` / `float` (or `None`) | `1` or `0` |
| 11 | `Property_Area` | `str` | `"Urban"`, `"Semiurban"`, `"Rural"` |

Engineered inside the pipeline automatically:
- `TotalIncome = ApplicantIncome + CoapplicantIncome`

## 3. Class Mapping & Probability Output

- **Target mapping during training:**
  - `"Y"` → `1` → `"Approved"`
  - `"N"` → `0` → `"Rejected"`
- **Probability availability:**
  - `model_pipeline.predict_proba(df)` is available and returns `[P(Rejected), P(Approved)]`.
  - Class `1` (`Approved`) probability is `model_pipeline.predict_proba(df)[0, 1]`.
  - Class `0` (`Rejected`) probability is `1.0 - approval_probability`.

## 4. How Member 2 Loads and Calls the Model

You can either call `ml/src/predict.py` directly or load `model_pipeline.joblib` yourself:

```python
from ml.src.predict import build_input_dataframe, load_model_artifacts, predict_loan_application
from ml.src.explainability import explain_single_application, load_shap_background
from ml.src.train import SAVED_MODELS_DIR, SHAP_BACKGROUND_FILENAME

# 1. Load once at FastAPI startup
model_pipeline, metadata = load_model_artifacts()
shap_background = load_shap_background(str(SAVED_MODELS_DIR / SHAP_BACKGROUND_FILENAME))

# 2. Predict for one applicant dictionary (11 keys)
payload = {
    "Gender": "Male",
    "Married": "Yes",
    "Dependents": "0",
    "Education": "Graduate",
    "Self_Employed": "No",
    "ApplicantIncome": 5720,
    "CoapplicantIncome": 0,
    "LoanAmount": 110.0,
    "Loan_Amount_Term": 360.0,
    "Credit_History": 1.0,
    "Property_Area": "Urban",
}
prediction_result = predict_loan_application(
    model_pipeline,
    payload,
    model_version=metadata.get("model_version", "v1.0.0"),
)

# 3. Explain for Member 3 / POST /explain
input_df = build_input_dataframe(payload)
explanation_result = explain_single_application(
    model_pipeline,
    input_df,
    background_transformed=shap_background,
)
```

### Expected `predict_loan_application()` Output Keys
- `prediction`: `"Approved"` or `"Rejected"`
- `predicted_label`: `1` or `0`
- `approval_probability`: float (`0.0` to `1.0`)
- `rejection_probability`: float (`0.0` to `1.0`)
- `confidence_band`: `"High"`, `"Moderate"`, or `"Uncertain / Borderline"` (`0.40 <= p <= 0.60`)
- `human_review_recommended`: `bool` (`True` when `0.40 <= p <= 0.60`)
- `engineered_features`: `{"TotalIncome": float}`
- `model_version`: string (`"v1.0.0"`)
- `disclaimer`: prototype notice string

### Expected `explain_single_application()` Output Keys
- `prediction`, `approval_probability`
- `explainer_type`: `"LinearExplainer"` (automatically adapts if retrained model changes to a tree model)
- `base_value`: float
- `contributions`: list of `{"feature", "input_value", "shap_value", "direction"}` (one-hot columns already summed back to original input names)
- `summary_points`: top 3 plain-English contributor bullets
- `causation_notice`: statistical attribution disclaimer (not real-world causation)
